# קֶשֶׁר — משחק הקשרים

משחק קשרים בעברית. בונים שרשרת אחת מ־25 כרטיסים, וכל כרטיס חדש מתחבר לקודם.
המערכת מזהה את עומק הקשר ומסבירה אותו לפי ארבע רמות, בהשראת הפרד״ס:

| רמה | משמעות | ניקוד |
| --- | --- | --- |
| פָּשָׁט | קשר גלוי | 5 |
| רֶמֶז | קשר סמלי | 10 |
| דְּרָשׁ | קשר מופשט | 18 |
| סוֹד | קשר נסתר | 30 |

**חיבורי שרשרת:** כשמחברים A ל־B ואחר כך B ל־C, המערכת חושפת גם את הקשר A–C ומוסיפה בונוס של 40%.

## מה יש במשחק

- 5 דקות למשחק, השהיה אוטומטית כשעוברים לאפליקציה אחרת, ותפריט השהיה עם סיום מוקדם.
- קווי חיבור צבעוניים לפי רמת הקשר, עם אנימציה.
- צלילים (Web Audio, בלי קבצים) ורטט בנייד, עם אפשרות כיבוי.
- שיא אישי, היסטוריית משחקים ואוסף "סודות" שנשמרים במכשיר.
- ניתוח סגנון חשיבה, מפת קשרים ושיתוף תוצאה בלי ספוילרים.
- אפליקציה מתקינה (PWA) שעובדת גם בלי אינטרנט.
- נגישות: ניווט במקלדת עם חצים, תוויות לקוראי מסך, וכיבוד הגדרת "הפחתת תנועה".

## פיתוח

```sh
npm install
npm run dev        # שרת פיתוח בפורט 8080
npm test           # בדיקות (Vitest)
npm run lint       # ESLint
npm run typecheck  # TypeScript
npm run build      # בנייה לפרודקשן (כולל service worker)
```

## מבנה הקוד

| קובץ | תפקיד |
| --- | --- |
| `src/game/gameItems.ts` | 25 הכרטיסים, ניקוד, אבני דרך וצבעי רמות |
| `src/game/evaluator.ts` | מנוע הערכת הקשר: סודות שנכתבו ידנית, ארכיטיפים, תגיות וקטגוריות |
| `src/game/engine.ts` | לוגיקת המשחק כ־reducer טהור (בחירה, שרשראות, טיימר, השהיה) |
| `src/game/personality.ts` | ניתוח סגנון החשיבה בסוף המשחק |
| `src/hooks/useGameState.ts` | חיבור המנוע ל־React: טיימר, צלילים ושמירת נתונים |
| `src/lib/` | שמירה מקומית, צלילים ורטט, שיתוף |
| `src/components/` | מסך פתיחה, מסך משחק, מסך תוצאות, קווי חיבור ותפריט השהיה |

הפרויקט נבנה ב־[Lovable](https://lovable.dev) (Vite, React, TypeScript, Tailwind ו־shadcn/ui), ואפשר להמשיך לערוך אותו שם.
